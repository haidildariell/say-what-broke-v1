## How to run

```sh
python3 main.py
```

This writes the entry line (161 characters, single line, no trailing newline) to `/output/entry.txt`. If `/output` is not writable, it falls back to `./output/entry.txt`.

## The line

> Your file didn't fail to upload. Our server ran out of disk because we've saved every log since 2019. It's us, not you. We're the incident. Try again in an hour.
